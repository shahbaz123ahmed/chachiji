# Chachiji — Authentic Handcrafted Achar & Mithila Makhana

A premium, modern D2C e-commerce platform for **Chachiji's Homemade Cuisine**, crafted in Vaishali & Mithila, Bihar.

![Chachiji Storefront](https://images.unsplash.com/photo-1596797038530-2c107229654b?auto=format&fit=crop&w=1200&q=80)

---

## 🌶️ Features

- **Heritage Culinary Catalog**: Handcrafted sun-cured pickles in ceramic martabans, GI-tagged Mithila wetland makhana, and curated gift boxes.
- **Solid Brand Design System**: Crafted with the exact Chachiji color palette:
  - **Primary (Deep Red)**: `#8B3E3E`
  - **Secondary (Peach)**: `#F7A77A`
  - **Soft Background (Cream)**: `#FCE9D6`
  - **Typography (Charcoal)**: `#333333`
  - **Base Canvas (White)**: `#FFFFFF`
- **Dynamic Shopping Experience**:
  - Slide-over Cart Drawer with real-time free shipping progress meter.
  - Multi-coupon engine (`CHACHIJI10`, `MITHILA50`, `HERITAGE100`).
  - Interactive product detail view with multi-weight variant switcher, postal pincode delivery estimator, nutrition breakdowns, and customer reviews.
  - Category filters, spice level filters, instant search overlay (`⌘K`), and sorting.
  - Distraction-free multi-payment checkout (COD, UPI, Cards).
  - Simulated live order confirmation with confetti and milestone shipment tracker (`/track-order`).
  - Dedicated Admin Operations Console (`/admin`) with revenue analytics charts and recent orders management.

---

## 🛠️ Tech Stack

- **Framework**: [Next.js 16 (App Router)](https://nextjs.org/)
- **Language**: TypeScript
- **Styling**: Tailwind CSS v4 with custom design tokens
- **Icons**: Lucide React + custom Mithila brand icons
- **State Management**: React Context (`CartContext`, `WishlistContext`, `SearchContext`) with `localStorage` persistence

## 🚀 Getting Started

### Prerequisites

- Node.js 18.18+ or later
- npm or yarn

### Installation

1. Clone the repository:
```bash
git clone https://github.com/shahbaz123ahmed/chachiji.git
cd chachiji
```

2. Install dependencies:
```bash
npm install
```

3. Run the development server:
```bash
npm run dev
```

4. Open [http://localhost:3000](http://localhost:3000) in your browser.

---

## 📦 Production Build

```bash
npm run build
npm run start
```
